in notes
================================================================================
1. DROP: --> removes the table or object 
         --> table structure + data
         --> table structure removed
         --> performance is slow(due to full removal)

2. DELETE: --> removes specific rows from a table
           --> specific rows(based on condition)
           --> table structure intact
           --> performance is slower (row-by-row)
 
3.TRUNCATE: --> removes all rows, keeps structure
            --> all rows
            --> table structure intact
            --> performance is fast(bulk deletion)
=================================================================================
