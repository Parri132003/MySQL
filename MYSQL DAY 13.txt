 SET OPERATORS
---------------
UNION :- COMBINE RESULTS FROM TWO QUERIES AND REMOVES DUPLICATE ROWS. COLUMN MUST HAVE THE SAME NUMBER AND TYPE
UNION ALL:- COMBINES RESULTS FROM TWO QUERIES AND INCLUDE ALL ROWS . INCLUDING DUPLICATES .COLUMN MUST HAVE THE SAME NUMBER AND TYPE
INTERSECT:- RESULTS ROWS THAT ARE COMMON TO BOTH QUERIES.COLUMNS MUST HAVE THE SAME NUMBER AND TYPE.
NOTE- MYSQL DOESN'T SUPPORT INTERSECT DIRECTLY.
MINUS/EXCEPT:- RESULTS ROWS FROM THE FIRST QUERIES THAT ARE NOT PRESENT IN THE SECOND QUERY.COLUMNS MUST HAVE THE SAME NUMBER AND TYPE.

JOINS
a join in MYSQL is used to combine rows from two or more tables based on related columns.

example:-employees table----->employee details.
         department table---->department details.

if you want to see which employee belongings to which department, you need to join these two tables.

why do we need joins
---------------------
1.to fetch data from multiple tables in a single query.
2.to reduce data duplication (instead of keeping everything in one table).
3.to implement relationships like(one-to-one ,one-to-many ,many-to-one ,many-to-many ).
4.to generate reports and analytics combing different datasets.
   
types fo joins
---------------
1.inner join:-returns only the rows that have matching values in both tables.
       syntax:  select columns
                from table 1
                inner join table2
               on table1.common_column=table2.common_column;

2.left join:-returns all rows from the left table and the matched rows from the right table. 
              if no match null values appear for the right table columns.
       syntax:   select columns
                 from table 1
                 left join table2
                on table1.common_column=table2.common_column;


3.right join:-returns all rows from the right table and the matched rows from the left table. 
              if no match null values appear for the left table columns.
       syntax:   select columns
                 from table 1
                 right join table2
                on table1.common_column=table2.common_column;

4.full join:-to simulate the use the UNION of LEFT join and RIGHT join
        syntax:   select columns
                 from table 1
                 left join table2
                on table1.common_column=table2.common_column;


5.cross join:-returns cartesian product --> every row from the first table with every row from the second table
         syntax:  select columns
                  from table 1
                 cross join table2; 

6.self join:- a table joined with itself.
               select a.columns,b.columns
                 from table1 a
                inner join table1 b
               on a.common_column=b.common_column;
